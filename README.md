# Apex Racing 3D: Tour of the 7 Wonders of the World 🏆

A high-performance 3D arcade hypercar racing game built with Three.js and Vite. Experience authentic physics in a Ferrari 458 Italia across a 24-meter multi-lane circuit touring the Seven Wonders of the World.

## Features
- **Official Ferrari 458 Italia**: Metric scale 3D model with realistic suspension pitch & roll, functional steering wheel, and spinning alloy wheels.
- **7 Sculpted World Wonders**:
  1. Neo-Tokyo Metropolis & Skytree
  2. Alpine Mountain Summit Canyon
  3. Giza Pyramids & Great Sphinx
  4. Imperial Roman Colosseum & Arch
  5. Pacific Paradise Ocean Highway & Lighthouse
  6. Cyber Hyper-Tunnel with glowing laser hex-rings
  7. Victory Grand Prix Stadium with Golden Winged Victory Trophy
- **Arcade Driving Controls**:
  - **W** / **Up**: Accelerate
  - **S** / **Down**: Dedicated Reverse gear
  - **Space**: Dedicated Brake / Handbrake Drift
  - **Shift**: Nitrous Boost (NOS)
  - **A** / **D** / **Left** / **Right**: Steer
  - **R**: Instant Checkpoint Reset
- **High-Fidelity Audio**: Procedural Web Audio engine sound with 7-speed transmission RPM curves, screeching tires, nitrous boost, and checkpoint chimes.
- **Race HUD**: Dynamic tachometer, digital speedometer, minimap radar, checkpoint split timer, and drift counter.
